# Orix Chrome Extension

**Orix** is a simple Chrome extension that provides instant word definitions when you double-click on any word on a webpage.

---

## 🌟 Features

* **Instant Definitions**: Double-click any word to see its definition.
* **Responsive**: Popup adjusts with screen resizing or scrolling.
* **Minimal UI**: Clean and distraction-free interface.

---

## 🚀 Installation

1. Clone the repo:

   ```bash
   git clone https://github.com/yourusername/orix.git
   cd orix
   ```

2. Load the extension in Chrome:

   * Go to `chrome://extensions/`
   * Enable **Developer mode** and click **Load unpacked**.
   * Select the `Orix` folder.
